 1. `from decouple import config`:
       * Purpose: python-decouple is a library that helps you organize your settings by separating parameters that change between deployments (like
         database credentials, API keys, debug mode) from your code.
       * How it's used here: config('DATABASE_URL') is likely used to read the DATABASE_URL environment variable. This means sensitive information or
         environment-specific settings are not hardcoded directly into your settings.py file, but rather loaded from environment variables (or a .env
         file).
       * Benefit: This is a best practice for security and maintainability, as it prevents sensitive data from being committed to version control and
         makes it easy to switch configurations between development, staging, and production environments.


   2. `import dj_database_url as db_url`:
       * Purpose: dj-database-url is a Django utility that allows you to configure your database connection using a single URL string (e.g.,
         postgres://user:password@host:port/dbname).
       * How it's used here: db_url.parse(config('DATABASE_URL')) takes the database URL string (retrieved via decouple.config) and parses it into a
         dictionary format that Django's DATABASES setting expects.
       * Benefit: This simplifies database configuration, especially in cloud environments (like Heroku, Render, etc.) where database connection
         details are often provided as a single environment variable. It makes your settings.py cleaner and more portable.
